# Sentiment analysis of Baulder's Gate 3 Steam Reviews

## Problem Statement
We will be analyzing the performance of Traditional Sentiment Models vs Fine-tuned BERT vs LLMs on sentiment analysis of the game “Baldur’s Gate 3” based on the reviews scraped from the game store Steam. The goal of the analysis will be to determine which type of model is better at predicting the sentiment of modern reviews that are primarily based on gamer lexicon that isn’t as inherent in what makes a “positive” review versus a “negative” review. We will be comparing the output of traditional models via TF-IDF + Logistic Regression, Fine-tuned BERT, and LLMs using zero-shot prompting and few-shot prompting.
## Dataset
We have decided to use a dataset titled [“Baldur's Gate 3 Steam Reviews”](https://www.kaggle.com/datasets/harisyafie/baldurs-gate-3-steam-reviews) found on Kaggle. This dataset features reviews of the game Baldur’s Gate 3 that were written on the platform Steam. This will be an interesting test of how well the models perform due to the use of not only video game language, but also locations and people from the game. The dataset has columns for the review itself, but also if it was a positive or negative-rated review for the game, which the user decides when they first write the review. 
## Expected Results
For comparisons, we will be using Accuracy and F1 scores, but accuracy is a better predictor of success since there are low stakes to our False Negatives and False Positives, and the main goal is to determine which model is better at predicting the sentiment of common review language in the game setting. The primary reason we chose this dataset is because it has a variety of sarcastic samples, joke reviews (ex: “im down bad” is a positive review), and robust, well thought out reviews for both positive and negative reviews. The final metric will be computational efficiency, measured by how fast each of the models completes the training and testing phases.
